# Expense Tracker — Dark Premium

## Запуск
1. Откройте эту папку в VS Code.
2. В терминале выполните `npm install`.
3. Затем `npx expo install --fix`.
4. Запустите `npx expo start -c`.
5. Для браузера нажмите `w`.

## Новые страницы
- Login / Register: локальная регистрация и вход.
- Dashboard: баланс, краткая статистика и быстрые действия.
- Expenses: история, поиск и фильтры.
- Savings Goals, Analytics, Subscriptions, Financial Calendar, Finance Assistant, Achievements.

## Важно
Авторизация и финансовые данные в этой учебной версии хранятся локально на устройстве. Это демонстрационный прототип, не подключённый к серверу и не предназначенный для хранения настоящих паролей или банковских данных. Для реального приложения нужно подключить backend с безопасным хешированием паролей и авторизацией.
